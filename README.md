# Pong Game (Python Turtle)

A simple Pong game built with Python and the Turtle graphics module.

The game features two controllable paddles, a bouncing ball, score tracking, collision detection, increasing ball speed, and a classic retro Pong-style gameplay experience.

This project was built using Object-Oriented Programming principles and multiple separate classes for game components.

---

## Features

- Two-player Pong gameplay
- Ball collision with walls and paddles
- Score tracking system
- Ball reset after missed shots
- Increasing ball speed during gameplay
- Middle field line
- Object-Oriented project structure
